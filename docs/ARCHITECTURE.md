# Architecture

Sentinel is a local-first, human-reviewed claim triage application. The Streamlit UI calls local Python services directly; FastAPI exposes the same scoring service for integrations. The training command reads the configured CSV, removes documented target/leakage-risk fields, splits rows once with stratification, fits preprocessing only on training rows, and stores local artifacts under `models/`.

```text
CSV -> loader/schema + exclusions -> train/test split
                                -> XGBoost + Logistic Regression evaluation
                                -> training-only Isolation Forest
                                -> manifest, metrics, SHAP artifacts

Streamlit / FastAPI -> scoring service -> validated classifier + anomaly model
                                      -> optional isolated narrative provider
                                      -> SQLite audit event
```

## Local artifacts

- `xgboost_pipeline.joblib`: fitted preprocessing and classifier.
- `logistic_baseline.joblib`: fitted preprocessing and baseline classifier.
- `isolation_forest.joblib`: training-fitted preprocessor and anomaly detector.
- `metrics.joblib`: held-out evaluation metrics, curves, and threshold analysis.
- `global_explanations.joblib`: mean absolute SHAP values on up to 500 held-out rows, or an explicit unavailable reason.
- `manifest.json`: dataset fingerprint, target, schema, split, timestamp, exclusions, version, and metrics.

Only load artifacts generated by a trusted local training run. Joblib/pickle artifacts can execute code when loaded; do not load artifacts from unknown sources. Raw input is read as CSV and never executed. Current app functionality supports a configured local file and API scalar JSON, not arbitrary uploaded files.

SHAP contributions use XGBoost's native TreeSHAP `pred_contribs` implementation. Feature names come from the fitted `ColumnTransformer`, including one-hot-expanded categorical levels.

## API

Run `uvicorn src.api.main:app --host 127.0.0.1 --port 8000`. Routes are documented at `/docs`. Batch scoring is capped at 100 claims. Model schema mismatches return actionable 422 errors. Request IDs are returned as `X-Request-ID` and safe generic server errors are correlated with structured log entries.

Example:

```json
{
  "claim_reference": "case-2026-001",
  "features": {
    "Month": "Dec",
    "WeekOfMonth": 2,
    "DayOfWeek": "Monday",
    "Make": "Honda"
  }
}
```

The example is illustrative only; submit exactly the feature names in the installed model manifest. Omitted or extra fields are rejected.

## Persistence and privacy

SQLite stores score, separate anomaly signal, threshold, model version, narrative, explanation, and UTC timestamp. A supplied external reference is stored only as a SHA-256 digest. The database is local and excluded from Git. Read [Security and privacy](SECURITY_AND_PRIVACY.md) before handling real claim data.
